# Assumptions register

| ID | Assumption | Evidence | Stated/Inferred | Impact if wrong | Review owner |
|---|---|---|---|---|---|
| A1 | The target is a git work tree and `main` or `master` is never written. | `docs/design.md`, `docs/architecture.md`, `src/nightshift/safety.py`, `src/nightshift/gitops.py` | Stated | Nightshift could dirty the operator default branch and break the review contract. | Nicolas Cravino / sw30labs |
| A2 | Host checks are local subprocesses and their exit status is the only proof a job is done. | `docs/design.md`, `docs/architecture.md`, `src/nightshift/host.py` | Stated | LLM self-grading could mark unverified work done. | Nicolas Cravino / sw30labs |
| A3 | The writer has no network and can edit only files in the current job `paths[]`. | `docs/design.md`, `README.md`, `src/nightshift/graph.py`, `tests/test_writer_path_lock.py` | Stated | Gold-plating or unrelated edits could escape the frozen brief. | Nicolas Cravino / sw30labs |
| A4 | A malformed or empty check command should fail the job, not abort the whole night. | `src/nightshift/host.py`, `tests/test_host_check.py`, `docs/architecture.md` | Inferred | One bad critic command could kill the overnight run. | Nicolas Cravino / sw30labs |
| A5 | Scoped commits use `git commit --only` so pre-existing staged work survives. | `docs/architecture.md`, `src/nightshift/gitops.py`, commit `ab38424` | Stated | Nightshift could commit operator WIP into the night branch. | Nicolas Cravino / sw30labs |
| A6 | CMM levels are derived only from forum evidence and an empty forum means L0. | `README.md`, `docs/design.md`, `src/nightshift/cmm.py` | Stated | Invented maturity scores would mislead portfolio decisions. | Nicolas Cravino / sw30labs |
| A7 | Portfolio priority execution is opt-in and starts paused during the org refactor. | `docs/portfolio-priorities.md`, `src/nightshift/priorities.py`, `src/nightshift/bag.py` | Stated | Nightshift could run against owner strategy without authorization. | Nicolas Cravino / sw30labs |
| A8 | The initial portfolio contract is one target and two jobs with no automatic meta slot. | `docs/portfolio-priorities.md`, `src/nightshift/bag.py` | Stated | Meta Nightshift could consume portfolio service credit without owner allocation. | Nicolas Cravino / sw30labs |
| A9 | Writer and critic are separate local servers and pointing both at one server is unsupported. | `docs/design.md`, `src/nightshift/config.py` | Stated | Resource contention or self-grading could degrade the loop. | Nicolas Cravino / sw30labs |
| A10 | The `auto` writer model is resolved from the live `/v1/models` endpoint. | `src/nightshift/config.py`, `src/nightshift/llm.py`, commit `d35dc69` | Stated | A stale hard-coded model id could make the night fail at first call. | Nicolas Cravino / sw30labs |
| A11 | Thinking effort and token budget are sized so chain-of-thought plus JSON fits the context. | `src/nightshift/llm.py`, `tests/test_thinking_effort.py`, commit `2352b96` | Stated | Truncated JSON or missing patches could stall the writer. | Nicolas Cravino / sw30labs |
| A12 | Halt is cooperative and the current turn finishes before the night stops. | `docs/design.md`, `src/nightshift/status.py`, `tests/test_halt_request.py` | Stated | Hard kill could leave half-written files or an inconsistent board. | Nicolas Cravino / sw30labs |
| A13 | Bag liveness is determined by `pid_alive` and not by `status.live_owner`. | `docs/architecture.md`, `src/nightshift/bag.py` | Stated | The deck own pid could be mistaken for a stale bag and allow concurrent runs. | Nicolas Cravino / sw30labs |
| A14 | Forum reuse keys cross repos using `check_hash + paths` and not `repo_id`. | `docs/architecture.md`, `src/nightshift/forum.py` | Stated | The same fix would not be visible across the estate. | Nicolas Cravino / sw30labs |
| A15 | The docs gate treats missing ADRs or assumptions register as job 1. | `README.md`, `docs/adr/0007-docs-gate.md`, `src/nightshift/docs_gate.py` | Stated | Retrospective decisions could remain undocumented. | Nicolas Cravino / sw30labs |
| A16 | The command deck is stdlib HTTP on loopback and accepts same-origin JSON only. | `docs/design.md`, `src/nightshift/deck.py`, commit `e42b50a` | Stated | A remote or non-JSON request could turn the deck into an unsafe control surface. | Nicolas Cravino / sw30labs |
| A17 | pytest checks strip CI addopts by inserting `-o addopts=`. | `docs/architecture.md`, `src/nightshift/host.py`, `tests/test_host_pytest_addopts.py` | Stated | A repo-level `--cov` could make every check fail for unrelated reasons. | Nicolas Cravino / sw30labs |
| A18 | The default state home is `~/.nightshift` and JSON files are the durable store. | `docs/architecture.md`, `src/nightshift/config.py` | Stated | State could be lost or collide with target repos. | Nicolas Cravino / sw30labs |
| A19 | Last night attempted checks are voided and not retried. | `README.md`, `src/nightshift/ledger.py`, `tests/test_ledger_void.py` | Stated | The loop could repeat the same failing job forever. | Nicolas Cravino / sw30labs |
| A20 | The product is a reviewable branch and not an automatic merge. | `README.md`, `docs/design.md` | Stated | Nightshift could land unreviewed changes. | Nicolas Cravino / sw30labs |
